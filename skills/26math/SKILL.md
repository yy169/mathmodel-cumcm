# 26math

这是`mathmodel-skill`的稳定轻量入口。

1. 完整任务只使用`../mathmodel-skill/SKILL.md`作为核心流程。
2. 所有阶段、reference、脚本、模板和状态路径均相对于
   `../mathmodel-skill/`解析。
3. 核心引擎不存在或不可读时立即报告，不得退回旧提示词流程。
4. 用户只要求读题、代码调试、单项审查或排版时，只进入相关阶段，不运行完整十阶段。
5. 用户要求“先讨论再修改”时，未经确认不得改文件或启动全量求解。
6. 题目把“信度、显著性、两类错误、功效、OC概率、后验区间”混用时，先走核心引擎的
   统计语义门禁，未完成映射不得锁定数值或摘要。

默认采用`standard`模式；只有用户明确要求冲刺、终稿红队或提交前冠军级审查时才使用
`championship`。额度敏感时使用`economy`。
