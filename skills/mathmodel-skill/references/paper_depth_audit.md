# 优秀论文篇幅与证据密度诊断

在 Stage 8 初稿完成后、Stage 9 终审时，以及用户提出“页数太少”“不像优秀论文”
时读取本文件。目标不是凑页数，而是识别“代码和实验已经完成、论文却没有展示完整证据”
的问题。

## 1. 核心原则

1. **页数合规不等于论文有竞争力。** “未超过上限”只说明没有违规，不能据此判断
   建模、求解和验证是否充分。
2. **不得把优秀论文页数当作官方获奖阈值。** 参考论文只用于校准结构、证据密度和
   展开程度；先区分正文、参考文献、附录和代码截图页。
3. **先诊断，再扩写。** 用户要求先分析时，不得立即改正文。先提交问题清单和逐页
   扩写蓝图，确认后再编辑。
4. **只增加可验证信息。** 允许增加推导、参数选择、对照实验、消融、稳健性、负面
   结果、图表和解释；禁止用通用背景、教材介绍、重复结论或代码截图填页。

## 2. 必做页数拆分

对当前 PDF 和用户提供的优秀论文分别记录：

| 指标 | 含义 |
|---|---|
| 总页数 | PDF 页数 |
| 摘要与前置页 | 摘要、目录、承诺书等 |
| 有效技术正文 | 从问题重述到模型评价，不含参考文献和附录 |
| 核心技术页 | 数据、模型、求解、结果和检验所占页数 |
| 参考文献页 | 文献列表 |
| 附录/代码页 | 支撑材料、代码、AI 披露 |

比较参考论文时必须说明“28 页正文 + 39 页代码”与“67 页论文”不是同一概念。
若 PDF 是扫描件，可用逐页渲染或 OCR 判断分界，不得只读取 PDF 总页数。

## 3. 证据密度审计

按章节统计文本量、公式、图、表和算法框，并检查每个小问是否具备：

`问题 → 假设 → 推导 → 参数/约束 → 求解器 → 结果 → 验证 → 解释`

出现下列任一情况即标记为“内容压缩风险”：

- 三个以上小问共用很短的“模型建立与求解”章节；
- 代码实现了多项实验，但正文只报告最终数字；
- 结果表没有初值、边界、参数估计、分角度结果或评价指标；
- 一个复合图塞入过多诊断，正文没有逐项解释；
- 创新点只有方法名称，没有基线、消融、效率或稳健性证据；
- 可靠性分析只给 RMSE 或单一置信区间；
- 负面结果、失效条件和参数相关性只在代码/报告中出现；
- 页面明显稀疏，或核心模型在一两页内跳过关键中间步骤。
- 若缺口主要来自图表不足、复合图过载或诊断未展示，继续读取
  `figure_evidence_system.md`，先构建图表证据链，再扩写正文。

## 4. 逐小问最低证据单元

每个小问至少应出现以下与其复杂度相称的内容：

1. 一个可解释基线及其数值结果；
2. 主模型的完整公式、变量、参数、边界和求解步骤；
3. 至少一张结果图或结果表；
4. 至少一种直接验证：对照、消融、敏感性、稳健性或可验证案例；
5. 对结果的物理/业务解释；
6. 一个具体限制或失败回退方案。

复杂逆问题、优化问题或多阶段耦合问题通常还需要：

- 初值来源和局部最优检查；
- 参数可辨识性或相关性；
- 算法收敛、运行时间或成功率；
- 模型形式不确定性与随机误差分开报告。

## 5. 自适应篇幅规划

不设置固定获奖页数。根据小问数量、模型复杂度和官方页数上限制定“证据预算”。
可用以下范围作为初稿规划启发，而非硬性标准：

- 摘要：1 页；
- 问题重述、分析、假设和符号：2–4 页；
- 数据审计与预处理：1–3 页；
- 每个主要小问的模型、求解和结果：3–6 页；
- 全局检验、敏感性和不确定性：2–4 页；
- 模型评价：1–2 页；
- 参考文献和附录按规则另计。

若当前论文明显短于同题型参考论文，不直接要求“补到 30 页”，而要计算缺失的
证据单元。最终页数应由必要内容自然形成。

## 6. 扩写优先级

按以下顺序补充：

1. 缺失的推导和模型边界；
2. 数据质量、预处理和参数选择依据；
3. 求解流程、初值、约束与收敛；
4. 基线比较和创新消融；
5. 残差、敏感性、稳健性和不确定度；
6. 结果解释、负面结果与适用条件；
7. 版式调整。

最后才考虑缩放图表或调整段间距。不得先通过字体、行距和空白操纵页数。

## 7. 诊断输出模板

在改稿前输出：

```text
1. 当前总页数 / 有效技术正文页数 / 核心技术页数
2. 参考论文正文与代码附录的页数分界
3. 各章节文本、公式、图表和证据单元统计
4. 每个小问缺失的推导、实验和验证
5. “代码已有但论文未展示”的内容清单
6. 建议新增页面及其唯一证据任务
7. 禁止增加的填充内容
8. 预计修改后的合理页数区间
```

## 8. 案例校准

一次三小问光谱逆问题中，初稿共 16 页，但扣除摘要、参考文献和附录后，有效技术
正文约 12 页，真正的数据—模型—结果—检验链约 8 页；两篇同题优秀论文正文约
28–30 页。问题并非字号或空白，而是大量已运行内容未进入论文：工作带选择、初值与
边界、分角度对照、残差诊断、参数相关性、消融和负面结果均被压缩。该案例说明：

> 当“代码完成度”显著高于“论文证据展示度”时，应扩展证据链，而不是把页数通过。

这个案例只作诊断依据，不得推导出“优秀论文必须达到某个固定页数”。
