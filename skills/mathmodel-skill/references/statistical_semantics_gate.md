# 统计决策语义与Monte Carlo报告门禁

在题目使用“信度、把握、接受、拒绝、显著、功效、后验区间”等自然语言，或论文用随机
模拟估计概率、期望、后悔值时读取。目标是防止统计术语相似但随机对象不同。

## 1. 先做语义映射，后算数值

建立 `reports/statistical_semantics_registry.csv`，逐项记录：

`原题措辞 → 原/备择假设 → 受控错误或估计量 → 参数点/参数域 → 决策事件 → 数学约束`

必须区分：

- 置信水平/检验显著性控制原假设成立时的错误概率，不自动等于某备择点的功效；
- Type-II错误与功效必须绑定具体备择参数或参数域；
- 验收抽样的AQL/LTPD两点OC是对题意的操作化，若质量点并非题面给定，应参数化并说明；
- 只有在明确采用“正确行动概率”解释时，才能把自然语言百分比直接写成OC端点约束。

若题面存在多种合理映射，先比较解释及是否改变参数、目标或数值；能由标准定义唯一解决则
自动登记，否则分支建模或请求确认。改变映射会改变约束时必须重算；只修表述时禁止无故
重跑。

## 2. 不可能性结论限定解释范围

连续性、不可辨识性或无有限样本等证明若依赖强化后的解释，必须写成：

> 若将题意进一步强化为……，则……不可能。

不得把对某种全参数OC解释的反证写成“原题本身不可完成”。

## 3. 最优性与证据范围

- 网格、候选族或有限策略空间内的最优，只能在对应范围内表述；
- 精确计算描述数值评价方式，不自动升级为任意规则空间的全局最优；
- 比较语义分支的“决策稳健性”时，应在每个分支重新优化策略空间；只重算当前策略仅支持
  “该策略收益敏感”，不支持“最优策略不变”。

### 3.1 精确并列检查必须覆盖全部子问题

任何“最优”结论都要附带并列检查，并且**同一篇论文内的标准必须一致**。只在策略空间大的
那一问检查并列，是最容易出现的内部不一致。

- 并列判定用精确相等，不设容差。容差会造出算术本身并不产生的并列，是反向的错误。
- 存在并列时：表中标注，正文写明“不具有唯一最优策略”，并给出打破并列所需的最小参数
  变动量（该变动量本身要有计算和结果文件支撑，见 `manuscript_delivery_gates.md` §7.2）。
- 记录字段与大空间那一问对齐，例如 `tied_policies`、`number_of_exact_ties`、
  `gap_to_second_distinct`。

2024B 的问题三报告了 `number_of_exact_ties` 并声明“不存在精确并列”，问题二从未做同一
检查——而问题二情形3 恰好有一个：两个策略的订单期望利润位级相等。论文因此把并列解写成
了唯一最优，正文还进一步解释成“检测节约不足以覆盖成本”，实际是恰好持平。

**并列不是瑕疵，隐瞒并列才是。** 该例中并列反而解释了问题四的贝叶斯推荐为何切换：
在精确并列处，任何使上尾变重的参数不确定性都会打破平局。

## 4. 后验、预测与Monte Carlo误差

报告区间前先写清随机对象：

- 参数后验下的 `U(a,θ)` 分位区间是“条件期望效用的后验区间”；
- 包含订单/观测随机性的才是后验预测区间；二者不得简称成同一“利润区间”。

所有Monte Carlo估计至少登记样本数、随机种子、估计对象及误差度量。概率、均值、EVPI、
regret等按样本标准差、批均值或独立种子计算SE；有效数字不得超过模拟分辨率。极小正值若
与Monte Carlo误差同量级，报告为阈值上界或“数值上不可分辨于0”，不得展示伪精度。

### 4.1 冻结运行值与复核统计量是两个量

做独立种子复核后，正文中会同时存在两类数：

| 量 | 含义 | 配套误差 |
|---|---|---|
| 冻结固定种子的权威运行值 | 表格与结果文件报告的那一次 | 该次的**组内** MC 标准误 |
| N 次复核的均值 | 精度审计的产物 | **种子间**标准误（即均值的标准误） |

三条硬规则：

1. **降低有效位数时，正文、表格和图注必须同时改。** 只改叙述而表格照旧，会让同一指标在
   两页之内出现两个数，读者一律判定为算错。
2. **标准误只能挂在它所描述的那个估计量上。** 把种子间标准误挂到单次冻结运行值上是搭配
   错误，即使两个数各自都对。
3. 若确实要同时保留两者，必须显式命名：“表 X 为预先冻结的固定种子权威运行；均值与标准误
   来自 N 次独立复核，该固定种子为其中之一”，并说明二者并非同一数值的两种取值。

判断单次运行是否异常时，用**标准差**而不是均值的标准误——后者衡量“均值有多准”，
前者才衡量“单次结果有多散”。混用会把落在 1 个标准差内的正常结果误判为离群。

## 5. 写作一致性检查

摘要、问题分析、公式、结果表和结论必须使用同一映射。终审逐项核对：

1. 百分比究竟是置信水平、错误率、功效还是OC概率；
2. 概率绑定哪个真实参数点或参数域；
3. 区间对应参数、条件期望还是未来观测；
4. 改变解释是否需要重算；
5. 强结论是否超过候选族、语义分支和Monte Carlo精度。
